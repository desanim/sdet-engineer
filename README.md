# SDET Engineer Portfolio

A practical QA and SDET portfolio organized around two focused areas: performance engineering and UX/accessibility testing. Each area contains its own project files, methods, and evidence.

## Portfolio areas

### Performance Engineering

JMeter + Python performance test framework with a FastAPI mock target, synthetic test data, response-time analysis, and SLA quality gates.

- [Performance module and run guide](performance/README.md)
- [Performance test plans](performance/jmeter_plans/)
- [Vibe coding performance case study](performance/case_studies/vibe_coding_ai/)

### UX Testing and Accessibility QA

QA references and working templates for usability, user journeys, WCAG 2.2 checks, keyboard and screen-reader testing, and accessibility audit reporting.

- [UX Testing documentation hub](ux-testing/README.md)
- [UX testing foundations](ux-testing/foundations.md)
- [Accessibility reference library (English)](ux-testing/accessibility-reference.md)
- [Accessibility reference guide (Vietnamese)](ux-testing/accessibility-reference-vi.md)
- [16-week Accessibility QA roadmap](ux-testing/a11y-16-week-roadmap.md)
- [Accessibility audit report template](ux-testing/accessibility-audit-template.md)

## Repository structure

- performance/ — performance test framework, configuration, data, JMeter plans, and case studies
- ux-testing/ — UX testing and accessibility QA reference documents, test plans, and report templates
- .gitignore — repository-level exclusions
- README.md — portfolio entry point

## How to explore

Start with the overview in each module. For a code walkthrough, use the performance module README. For the accessibility track, begin with the reference library and then follow the roadmap's weekly deliverables.

This repository is a work in progress. Case study results should be read with their environment, scope, and test limitations.
